# Lexicon

One concept, one story element, permanently. Appending a second element for an
existing concept is drift and `check_book.py` will fail the build. The same is
true in reverse: one story element may stand for exactly one concept.

Seeded from `bible.md` with only the elements the bible itself establishes.
The generator appends a row when it introduces a genuinely new concept.
